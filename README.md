# Caluladora de Índice de Masa Corporal (IMC)
## Descripción del programa
Este proyecto consiiste en una calculadora de Índice de Masa Corporal desarrollada en Python. El programa solicita al usuario sus datos personales y físicos, calcula eel IMC a partir del peso y la estatura, y muestra un reporte organizado con los resultados.
## Tecnologías utilizadas
- Python
- Visual Studio Code
- Git
- GitHub
## Intrucciones de ejecución
1. Instalar Pythom en el equipo.
2. Descargar o clonar este repositorio de GitHub.
3. Abrir la carpeta del proyecto en Visual Studio Code.
4. Ejecutar el archivo calculadora_imc.py desde la terminal con el comando: python calculadora:imc.py
## Validaciones
El programa valida que los campos no estén vacíos y que la edad, el peso y la estatura sean datos numéricos. Esto permite manejar esntradas incrrectas sin que el programa se cierre inesperadamente.
